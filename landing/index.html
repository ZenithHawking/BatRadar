Doubts

FAQ

Is it free?
Yes — MIT licensed, free forever. The source is on GitHub.
Does it store my API keys?
Only the optional manual API key you enter in Settings, stored locally in %APPDATA%/batradar/ with base64 encoding. OAuth credentials are read live from Claude Code's and Codex's own files.
Mac / Linux?
Not yet. The app is built with Tauri, so a port is plausible, but the installer is Windows-only right now.
Why is the installer unsigned?
Code-signing certs cost money. Windows SmartScreen may warn — click More info → Run anyway. The source is auditable on GitHub if you'd rather build from scratch.
How often does it poll the API?
Default 30 seconds, configurable in Settings. Stays within Anthropic / OpenAI rate limits at any reasonable interval.
