How to get API keys
Claude (Anthropic)
Option A — OAuth (recommended):
Run claude login in terminal. Done!

Option B — API Key:
1. Go to console.anthropic.com → API Keys
2. Create Key → copy sk-ant-api03-...
Codex (OpenAI)
OAuth only (auto-detect):
1. Install: npm install -g @openai/codex
2. Run: codex
3. Login with ChatGPT account
4. BatRadar detects automatically. No key needed!
Gemini (Google)
OAuth only (auto-detect):
1. Install: npm install -g @google/gemini-cli
2. Run: gemini and login with Google
3. BatRadar detects automatically. No key needed!

Lưu ý: Từ 6/2026 Google chỉ cho phép tài khoản Gemini Code Assist Standard/Enterprise đăng nhập Google trên Gemini CLI. Tài khoản cá nhân dùng Antigravity thay thế.
Copilot (GitHub)
Auto-detect (no key needed):
Login GitHub Copilot in VS Code / JetBrains, or run gh auth login.
Copilot Free (2000 completions + 50 premium requests/tháng) cũng track được — bật tại github.com/settings/copilot.
OpenRouter
Tạo API key miễn phí tại openrouter.ai/keys rồi nhập vào ô OpenRouter API Key bên dưới.
Antigravity (Google)
Auto-detect (app phải đang mở):
1. Tải tại antigravity.google và login Google
2. Mở app Antigravity — BatRadar đọc quota từ app đang chạy.
Hiển thị 2 pool: Gemini và Claude+GPT, mỗi pool có limit 5h + tuần.
Key stored locally only. Never sent to any server except the provider's API.
